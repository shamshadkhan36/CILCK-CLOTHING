# CILCK CLOTHING (ESTD 2024) - E-Commerce & Custom Apparel Website

Modern streetwear e-commerce platform & custom merchandising portal built with **React**, **Vite**, and **Tailwind CSS**, designed in the style of [destinyclothing.in](https://destinyclothing.in).

## ⚡ Key Features

1. **Streetwear Aesthetics (Destiny Clothing Inspired)**
   * Dark modern monochrome theme matching the Cilck circular tailoring badge.
   * Marquee ticker displaying Mumbai workshop credentials, ESTD 2024, and fabric specs (240-400 GSM).

2. **Catalog & Category Filtering**
   * Oversized T-Shirts (240 GSM Bio-washed cotton)
   * Hoodies & Fleeces (380 GSM Heavy French Terry)
   * Mumbai Heritage Varsity Jackets (Melton Wool & Vegan Leather)
   * Embroidered Street Caps (100% Chino Twill)
   * Custom / Bulk Orders (B2B / College Fests)

3. **Interactive Shopping Cart & 1-Click WhatsApp Ordering**
   * Size selector (S, M, L, XL, XXL) & color picker
   * Add to Bag with instant visual feedback
   * Slide-out Cart Drawer with Free Shipping progress bar (Free above ₹999)
   * Discount coupon system (`MUMBAI10`, `FIRSTDROP`)
   * **Direct WhatsApp Checkout:** Pre-fills client WhatsApp (`+91 79776 20643`) with customer name, phone, address, and structured order items.
   * **Online UPI / COD:** Instant order placement with confetti celebration & order confirmation modal.

4. **Custom & Bulk Merchandising (Destiny Clothing Style)**
   * Interactive bulk quote generator with live pricing per piece based on garment type and quantity slider.
   * High-density Puff Print, Chenille Embroidery, and DTF options.
   * Direct inquiry sent to WhatsApp with full specs.

5. **Store Locator & Directions**
   * Detailed Mumbai GTB Nagar Railway Station address with landmark.
   * Direct Google Maps navigation link.
   * Click-to-call and click-to-WhatsApp.

## 🚀 Running the Project

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
The production bundle is compiled into the `dist/` directory, ready to deploy to **Vercel**, **Netlify**, **Hostinger**, or standard cPanel hosting.
